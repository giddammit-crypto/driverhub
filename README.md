# DriverHub 🐧

Electron-приложение для обнаружения оборудования, диагностики драйверов и безопасной установки пакетов в **Ubuntu**, **Debian** и **Astra Linux**.

## Возможности

* 🔍 **Сканирование шин PCI и USB:** детальное обнаружение видеокарт, сетевых и аудиоадаптеров, контроллеров и периферийных устройств.
* ⚙️ **Определение активных драйверов:** извлечение рабочих модулей ядра (`Kernel driver in use`, `lsusb -t` дерево драйверов).
* 🛡️ **Безопасная установка через Polkit:** повышение привилегий через системный `pkexec` без хранения паролей в приложении.
* 📋 **Защищённый allowlist пакетов:** исключение выполнения произвольных команд и установка только проверенных пакетов (`nvidia-driver`, `firmware-iwlwifi`, `firmware-linux-free`, `firmware-linux-nonfree`, `bluez`, `linux-firmware` и др.).
* 🧠 **Интеллектуальная диагностика (Qwen AI):** анализ конфигурации и объяснение неполадок понятным языком (опционально, при наличии API ключа).
* 📜 **Локальный аудит операций:** ведение журнала всех сканирований, проверок и установок в профиле пользователя.
* 🎨 **Нативный адаптивный интерфейс:** чистый CSS/JS без тяжёлых внешних фреймворков, оптимизированный под любые разрешения экрана и Wayland/X11.

## Требования

Для полного сканирования физического оборудования рекомендуется наличие утилит `pciutils` и `usbutils`:

```bash
sudo apt install pciutils usbutils
```

*(Если утилиты не установлены, приложение запустится в безопасном демонстрационном режиме).*

## Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/giddammit-crypto/driverhub.git
cd driverhub

# Установка зависимостей
npm install

# Запуск приложения
npm start
```

---

## Подключение Qwen AI (опционально)

Ключ API не хранится в репозитории или исходниках. Для активации AI-ассистента задайте переменные окружения перед запуском:

```bash
export QWEN_ENABLED=true
export QWEN_API_KEY='ваш-api-ключ'
export QWEN_BASE_URL='https://api.xkiro.com/v1'
export QWEN_MODEL='qwen/qwen3.8-max:free'

npm start
```

*При отсутствии ключа приложение полноценно выполняет локальную системную диагностику по встроенным правилам ядра Linux.*

## Архитектура и безопасность

* **Изоляция контекста:** включены `contextIsolation: true` и `sandbox: true` в `webPreferences`.
* **Политика безопасности контента (CSP):** строгий заголовок CSP предотвращает внедрение сторонних скриптов.
* **Фиксированный IPC:** renderer не имеет прямого доступа к Node.js, `execFile` или shell.
* **Защита от инъекций:** все системные команды вызываются в виде массива аргументов без shell-интерполяции.
* **Совместимость с Astra Linux:** дистрибутив определяется через `/etc/os-release`, соблюдается изоляция репозиториев и специфика ЗПС.
